# Premium Scope — AI Idea Validation OS

Related issue: #6  
Product type: Future premium Notion/template product  
Working product name: AI Idea Validation OS

---

## Product Promise

AI Idea Validation OS helps builders validate, score and prepare product ideas before they invest serious time building.

It turns raw ideas into:

- Clear problem statements
- ICP definitions
- Assumption maps
- Interview plans
- Competitor research
- Scored validation decisions
- Landing page experiments
- Waitlist tests
- GitHub-ready build scopes

---

## Free vs Premium Boundary

## Free Canvas

The free version helps someone decide:

> Should I build this idea, validate it first, research more, or pause?

It includes:

- Problem definition
- ICP canvas
- Assumption map
- Competitor snapshot
- Interview questions
- MVP boundary
- Simple scoring
- Verdict and next action

## Premium OS

The premium version helps someone run a complete validation sprint.

It includes databases, dashboards, prompts, examples, trackers and execution workflows.

# Premium Modules

## 1. Idea Database

A Notion database for all ideas.

Fields:

- Idea name
- Status
- Target audience
- Problem severity
- Score
- Validation stage
- Owner
- Next action
- Launch potential
- Notes

Statuses:

- Raw idea
- Researching
- Interviewing
- Landing page test
- Waitlist test
- Build MVP
- Paused
- Killed

## 2. ICP Database

A database of audience segments and ideal customer profiles.

Fields:

- Segment name
- User type
- Buyer type
- Pain level
- Current alternatives
- Budget signal
- Reachability
- Channels
- Notes

## 3. Assumption Tracker

A tracker for the assumptions that must be true.

- Decision impact

## 5. Customer Interview Tracker

A database for interview candidates and notes.

Fields:

- Name
- Segment
- Role
- Source
- Interview status
- Pain score
- Willingness to pay
- Key quote
- Follow-up action

---

## 6. Scoring Dashboard

A dashboard that summarises:

- Total score
- Problem severity
- ICP clarity
- Willingness to pay
- Distribution access
- Build complexity
- Risk level
- Decision verdict

Verdict rules:

- 80–100: Build MVP
- 60–79: Validate with landing page/interviews
- 40–59: Research more
- Below 40: Pause or reshape
